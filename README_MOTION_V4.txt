AutoReel Motion V4

Nouveau module : M5B Motion Designer

Animations incluses :
- KEYWORD_POP
- NUMBER_COUNT
- MEDICAL_CARD
- LIST_ITEM
- SECTION_TRANSITION
- CTA

Rendu :
- 1080 x 1920
- fond transparent
- ProRes 4444
- style médical moderne bleu/blanc
- mouvements courts et non surchargés

Installation :
1. Fermer AutoReel.
2. Extraire tout ce ZIP à la racine :
   C:\Users\yoana\Documents\ChatGPT\AutoReel
3. Lancer AutoReel_INSTALL_MOTION_V4.bat
4. Lancer AutoReel_BUILD_MOTION_V4.bat
5. La GUI se relance.
6. Cliquer sur « Préparer pour DaVinci Resolve ».
7. Lancer le Lua M11 dans Resolve comme d'habitude.

Le module n'utilise pas encore un gros modèle IA.
Cette V1 construit le moteur d'animation fiable.
La prochaine étape pourra ajouter un Creative Director IA local.
